# CS2 Configs

My CS2 configs for different scenarios and utility.

Drop these files at the following path: `path/to/cs2/folder/game/csgo/cfg`

Then just type `exec configname` without the `.cfg` in the console and done :)

> [!IMPORTANT]
> A lot of the files use bind commands, which have been since restricted (see [here](https://github.com/ValveSoftware/csgo-osx-linux/issues/4322)).
> 
> Add `-disable_workshop_command_filtering` to the game's launch options to solve this issue.

Currently have:
- `autoexec.cfg` to instantly setup.
- `lineup.cfg` to prepare QOL binds and settings for practicing lineups (sv_cheats)
- `knife.cfg` to spawn any knife model (sv_cheats)
- `clear.cfg` to clear the previous configs.
